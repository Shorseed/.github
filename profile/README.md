# Shorseed

A workspace for personal and experimental software projects.

It is used to collect code related to systems programming, general software engineering, AI experiments, etc. 

Projects may be exploratory, unfinished, or revised over time.

## Scope

Repositories here may include:
- Programming experiments
- Prototypes and technical studies
- Tools and libraries created for learning or research
- Long-term projects under active iteration

## Notes

Code quality and clarity matter, but not every repository is intended to be production-ready.

Some projects will exist primarily to explore ideas.
